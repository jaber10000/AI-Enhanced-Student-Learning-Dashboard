# 🎓 AI-Enhanced Student Learning Dashboard

An intelligent FastAPI-based system that analyzes student learning data, tracks progress, and provides data-driven insights for better academic performance.  
This project demonstrates how **Artificial Intelligence** can empower educators and students through interactive dashboards and real-time analytics.

---

## 🚀 Features

✅ **Student Performance Analysis** — Automatically process student scores and identify strengths & weaknesses  
✅ **AI-Driven Insights** — Suggests learning improvements based on data  
✅ **FastAPI Backend** — High-performance and modern Python backend  
✅ **CSV Dataset Integration** — Uses a dataset to store and analyze student learning progress  
✅ **Interactive REST API** — Provides endpoints for student analytics  
✅ **Deployable on Render / Railway / Fly.io**
